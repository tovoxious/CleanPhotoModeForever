# Changelog

## v1.0.0

- First release for WoW: Forever (Interface 16001).
- Hides nameplates, unit names, chat bubbles, floating combat text, soft-target icons, ground circles and highlights, outlines and loot sparkles, and addon frames attached to the world whenever the UI is hidden.
- Restores the exact previous values when the UI is shown, keeps any change you make while it is hidden, and recovers automatically after a reload, crash or logout.
- Options panel and `/cpm` slash commands.
